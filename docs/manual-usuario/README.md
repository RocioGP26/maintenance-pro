## Convenciones

- Las rutas entre comillas (`Órdenes de trabajo → Listado`) indican menú de la barra lateral.
- Los estados aparecen en **negrita** tal como se ven en pantalla.
- Lo que ves en el menú depende de tu **rol**, el **área** y los **módulos** contratados por tu empresa.
