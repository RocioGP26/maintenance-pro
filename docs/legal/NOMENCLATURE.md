# LEG · Nomenclatura

**Serie:** `RTX-{ÁREA}-{NNN}` · Sistema Documental Legal de Roustix · control en [RTX-DOC-000](RTX-DOC-000-control-versiones.md)

## Prefijos de área

| Prefijo | Área | Uso |
|---------|------|-----|
| `RTX-DOC` | Gobierno documental | Control de versiones del paquete |
| `RTX-LEGAL` | Contratos y términos | Términos de uso · Contrato SaaS |
| `RTX-PRIV` | Privacidad | Política y anexos de datos |
| `RTX-PRIV-ANX` | Anexos de privacidad | Subencargados · conservación · flujos |
| `RTX-SLA` | Nivel de servicio | SLA contractual opcional |
| `RTX-SUP` | Soporte | Política operativa de ayuda |
