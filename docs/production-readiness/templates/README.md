Estas plantillas continúan como borradores y requieren completar la identidad
del prestador y la revisión jurídica correspondiente antes de firmarse o
publicarse como documentos vigentes.

El SLA no debe firmarse ni anexarse a una venta hasta completar sus decisiones
pendientes y confirmar operativamente los objetivos de disponibilidad,
respuesta y créditos.

## Secuencia comercial recomendada

1. Propuesta comercial y cotización individual.
2. Contrato SaaS, privacidad, transmisión y Acta de Servicio.
3. Guía de onboarding y Acta de Capacitación.
4. Acta de Entrega y Aceptación para autorizar la activación.
5. Acta de Terminación y Constancia de Datos al finalizar el servicio.

Antes de publicar o firmar, los socios deben cerrar la matriz de decisiones y
obtener la revisión jurídica y contable aplicable. Para cada cliente, el
Checklist Maestro concentra el expediente y actúa como gate de activación.
