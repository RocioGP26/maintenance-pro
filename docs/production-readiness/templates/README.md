# Plantillas documentales

## Vigentes para operación comercial

- `01-PROPUESTA-COMERCIAL-ROUSTIX.docx` (versión 1.0)
- `03-PAQUETE-PRIVACIDAD-TRATAMIENTO-ROUSTIX.docx`
- `04-ACUERDO-TRANSMISION-DATOS-ROUSTIX.docx`
- `07-CONSTANCIA-DATOS-SALIDA-ROUSTIX.docx`
- `08-CONTRATO-SAAS-ROUSTIX.docx`
- `09-ACTA-SERVICIO-SELECCION-PLAN-ROUSTIX.docx` (versión 2.0)
- `10-POLITICA-SOPORTE-ROUSTIX.docx` (borrador versión 0.2.0)
- `11-ACUERDO-NIVEL-SERVICIO-SLA-ROUSTIX.docx` (borrador no vinculante versión 0.1.0)

Estas plantillas continúan como borradores y requieren completar la identidad
del prestador y la revisión jurídica correspondiente antes de firmarse o
publicarse como documentos vigentes.

El SLA no debe firmarse ni anexarse a una venta hasta completar sus decisiones
pendientes y confirmar operativamente los objetivos de disponibilidad,
respuesta y créditos.

## Archivo histórico

Las plantillas diseñadas exclusivamente para el programa piloto se conservan
en `historical/pilot/`. El programa fue archivado el 2026-08-09 antes de su
ejecución y estos archivos no forman parte del paquete comercial vigente.
